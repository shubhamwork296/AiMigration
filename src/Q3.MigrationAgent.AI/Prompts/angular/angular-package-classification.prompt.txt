ACTION RULES:
Use action upgrade when:
- The package is Angular-owned framework/tooling/CDK/Material and must align to the target Angular major.
- TypeScript, zone.js, rxjs, or tslib is proven incompatible with the target Angular major.
- A third-party Angular-coupled package is proven to block install/build and a safe compatible version is known from supplied metadata.

Use action preserve when:
- The package is unrelated third-party runtime/build tooling.
- The package is third-party Angular-coupled but no validation failure proves it blocks the hop.
- The current package version is compatible with the target Angular major.
- Upgrading may cause source-code impact and no validation failure proves it is required.

Use action remove when:
- The package is obsolete for the target Angular major.
- It directly blocks install/build.
- Removal is structurally safe and does not require source-code changes.
- Confidence is high.

Use action manual_review when:
- Compatibility cannot be determined.
- Exact target version cannot be safely recommended.
- The package appears to require source-code changes.
- The package is private/internal.
- The package conflict is high risk.
- Supplied failure context is incomplete.

TARGET VERSION RULES:
